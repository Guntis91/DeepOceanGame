\# Deep Ocean Game (Greenfoot)



A simple Greenfoot shooting game where you control a cannon in the middle of the ocean and shoot incoming sea creatures before they reach you.



This project was made as a learning game project using Java + Greenfoot.



---



\## Gameplay



\- Enemies (fish/turtle) spawn from the edges of the world.

\- They move towards the center.

\- You rotate the cannon and shoot bullets to stop them.

\- Each enemy you hit increases your score.

\- If an enemy touches the cannon, the game ends and the final score is shown.



---



\## Controls



\- Left Arrow = rotate left

\- Right Arrow = rotate right

\- Space = shoot



---



\## How to Run (Greenfoot)



1\. Install Greenfoot.

2\. Open Greenfoot.

3\. Click \*\*Open Project\*\*.

4\. Select the folder \*\*Deep Ocean\*\* (the one that contains `project.greenfoot`).

5\. Press \*\*Run\*\*.



---



\## Project Files (Main Classes)



\- `MyWorld.java` = spawns enemies and manages the game

\- `cannon.java` = player cannon controls and shooting

\- `bullet.java` = bullet movement and cleanup

\- `attackers.java` = enemies that move toward the center

\- `ScoreBoard.java` = shows the score

\- `lose.java` = game over screen and final score display
